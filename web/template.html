AI Business Analyst

Ask a business question in plain English. This page parses it, aggregates the data, decomposes what actually moved, and writes the answer — all in your browser, no server.

Revenue by month · all data
What this is. A standalone port of the Python project. The numbers come from the same generated database () — pre-aggregated into cubes at build time, with the contribution-to-change analysis re-implemented in JavaScript so the page genuinely computes rather than replaying canned answers.

Honest limitation. The cubes are one-dimensional, so this page can break down by any single dimension but cannot cross-filter (e.g. "Electronics in EMEA"). It also uses the rule-based engine, not a live LLM. The full Python app (streamlit run streamlit_app.py) has neither restriction.
